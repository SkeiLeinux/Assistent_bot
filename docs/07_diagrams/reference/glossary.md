## Глоссарий

Сводка ключевых терминов из ТЗ. Источник истины — `docs/04_specs/` и `docs/02_domain/DOMAIN_MODEL.md`.

### Ядро (Identity & Sharing)

- **Bounded context** — автономный домен с собственными моделью/сервисами/API; контексты связаны слабо, общее только ядро.
- **shared kernel** — ядро `Identity & Sharing`: единственный контекст, от которого зависят все остальные.
- **Viewer (зритель)** — аутентифицированный `User`, от лица которого выполняется запрос; вход любого фильтра видимости.
- **Family / Membership** — семья (пара, ≤2) и членство пользователя в ней.
- **Invite** — одноразовый инвайт-код для пейринга; FSM `active → used/expired/revoked`.
- **Shareable** — миксин видимости: `owner_id` + `family_id` + `scope` + `hidden_from`; примешивается к каждой разделяемой сущности.
- **scope** — режим видимости: `PERSONAL` (только владелец) или `FAMILY` (вся семья).
- **hidden_from** — множество исключённых пользователей при `FAMILY`; подарок = `FAMILY` + `hidden_from=[одаряемый]`.
- **visible_to(viewer)** — единый фильтр чтения; гарантирует, что зритель видит только разрешённое.
- **initData** — подписанные Telegram-данные Mini App; HMAC-валидация = аутентификация (без паролей/сессий).

### Lists

- **List / ListItem** — типизированный список (дела/покупки/идеи/фильмы/подарки/ссылки) и его элемент.
- **specific_attrs** — JSON-поле type-специфичных атрибутов элемента (валидируется по типу списка).
- **ListItemHistory** — action-лог изменений элемента (`CREATED/EDITED/STATUS_CHANGED/MOVED`), с капом.

### Finance

- **Import ACL** — anti-corruption layer: заменяемый адаптер `xlsx → доменная модель`; домен не зависит от формы таблицы.
- **Category** — двухуровневое дерево категорий; статус `ACTIVE / NEEDS_REVIEW`.
- **BudgetPlan / ActualAmount** — план по категории на месяц / факт с дневной гранулярностью (разрежённо).
- **Income / IncomeSource** — доход по источнику (партнёр/кэшбек/переходящий остаток) за месяц.
- **fail-loud** — при расхождении импорт не пишет ничего и возвращает отчёт об ошибках.

### Nutrition

- **FoodEntry** — запись личного дневника (PERSONAL); КБЖУ — абсолют за порцию.
- **SharedFood** — общий каталог блюд (FAMILY); КБЖУ на 100 г; работает как самонаполняющийся кэш.
- **NutritionGoals** — личные цели КБЖУ (PERSONAL, 1:1 на пользователя).
- **Resolver-ладдер** — лестница источников КБЖУ: `label → OFF → web (R2) → estimate`.
- **Провенанс (source / source_ref / matched_name)** — откуда взяты КБЖУ позиции (этикетка/OFF/веб/оценка) + ссылка.

### Reminders / Notifications

- **Reminder** — SSOT расписания: текст, `next_fire_at`, `recurrence`, `status`.
- **recurrence** — повтор: `NONE / DAILY / WEEKLY / INTERVAL`.
- **misfire-грейс** — окно (дефолт 3 ч), в пределах которого просроченное напоминание всё ещё доставляется; сверх — `MISSED`.
- **ack / snooze** — подтвердить выполнение / отложить (обе кнопки в push).
- **poll-loop (Scheduler)** — generic-планировщик: тик раз в N сек, выбирает созревшие (ADR-0003).
- **DeliveryReport** — результат доставки `{sent, blocked, failed}` (не персистится; Notifications stateless).
- **политика лог→ретрай→алерт** — на сбое доставки: лог, один ретрай транзиентного, затем алерт админу.

### Analytics & Digest / общее

- **read-side** — контекст без своей write-модели; читает другие домены через `contexts.*.read` и агрегирует on-the-fly.
- **DigestSchedule** — расписание дайджеста (per-семья, мульти-каденс: ежедневный + еженедельный).
- **Mini App** — весь интерактивный UI (React); говорит с backend по REST.
- **модульный монолит** — один процесс/одна БД, логически пакет-на-контекст (ADR-0004).
- **standalone-шов** — доменная логика Telegram-агностична; завязка на Telegram изолирована (kernel.auth + delivery).
