# Диаграммы — Use Case, BPMN, обзор, программа

**Назначение:** визуальный слой документации для презентации — «что есть в системе», «как происходят основные действия» и «куда идём (E2–E5)». Диаграммы **производные** от ТЗ / ADR / каркасов программы; **источник истины (SSOT)** — `docs/04_specs/`, `docs/03_architecture/`, `docs/06_program/`. При расхождении правится диаграмма, не наоборот.

**Охват:**
- Разделы 1–3, 5 — **MVP (реализовано/принято)**, SSOT `docs/04_specs`.
- Раздел 4 — **программа E2–E5 (проектное/кандидатное)**: каркас-видение, детальные ТЗ пишутся на входе этапа. Опросники Q2–Q4 открыты, ADR-кандидаты 0006–0012 не приняты. SSOT `docs/06_program`.

## Как смотреть

Открыть **`catalog.html`** в браузере — единая страница со всеми диаграммами + глоссарий и матрица трассировки. Mermaid рендерится сам, BPMN — через bpmn-js (зум колесом, панорама перетаскиванием). Нужен интернет (CDN). Боковая навигация по разделам. Программный раздел помечен жёлтым баннером «проектное/кандидатное».

## Нотация (гибрид)

- **Обзор, Use Case, карты возможностей, roadmap** — Mermaid (`.mermaid`).
- **Процессы** — BPMN 2.0 (`.bpmn`): Camunda/bpmn.io, автораскладка `bpmn-auto-layout`. Single-pool, роль автора несёт тип задачи (человек = Партнёр, шестерёнка = Система) + префикс в названии.

## Структура

```
07_diagrams/
  catalog.html              — сводный каталог (открывать его)
  overview/                 — обзор MVP (Mermaid): контекст, карта контекстов, видимость, контейнеры, фич-карта
  usecase/                  — Use Case MVP (Mermaid): системный + 6 доменов
  bpmn/                     — процессы MVP (BPMN 2.0): онбординг, списки, импорт, питание, напоминание, увед., дайджест
  program/                  — программа E2–E5 (Mermaid + BPMN, ПРОЕКТНОЕ):
                              roadmap · 3 контейнерные дельты · карта осуществимости ·
                              4 карты возможностей (E2–E5) · 5 кандидатных BPMN
  reference/                — справочное (Markdown): glossary.md · traceability.md
  _build/                   — скрипты пересборки (gen_bpmn*.py, layout.mjs, build_catalog.py, bpmn_src/)
```

## Как пересобрать

- **BPMN MVP:** `python3 _build/gen_bpmn.py` → `node _build/layout.mjs <src> bpmn/`.
- **BPMN программы:** `python3 _build/gen_bpmn_program.py` → `node _build/layout.mjs <src_program> program/`.
- **Каталог:** `python3 _build/build_catalog.py <путь к 07_diagrams>` (сканирует overview/ usecase/ bpmn/ program/ reference/).
