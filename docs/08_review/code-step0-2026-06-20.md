Безопасно: ни один живой модуль не импортирует (проверено grep), `alembic/env.py` тянет `app.db.base`, не `app.db.models` (комментарий в `env.py:7` про db/models — устарел, можно поправить). После — `lint-imports` + `pytest`.

3. **`alembic upgrade head`** на реальной БД (применит `b7c9d1e2f3a4`).
