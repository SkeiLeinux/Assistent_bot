## 3. Что смотреть в логе первые минуты

## 4. Smoke — 5 минут, руками

- [ ] **Текст:** «200 г гречки» → КБЖУ пришли.
- [ ] **Этикетка с парой кДж/ккал** — главная проверка релиза. Возьми ту же корейку или любой товар,
      где напечатано `NNN кДж / MM ккал`. Ожидание: ккал совпадают с **меньшим** числом. Если снова
      получишь ×4 — C3a не сработала, это блокер, откатывайся и пиши.
- [ ] **Позиция со штрихкодом в кадре:** бейдж `Open Food Facts` теперь может появиться только по
      штрихкоду. Появился на позиции без штрихкода → вариант D применён не полностью.
- [ ] **Тарелка из 3–4 позиций:** проверь на глаз, что стало быстрее. Поисковых запросов больше нет,
      ушло до 2,5 с ожидания на позицию.
