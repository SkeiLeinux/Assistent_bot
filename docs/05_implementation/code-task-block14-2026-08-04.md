# Задача для Claude Code: блок 14 — синхронизация `openapi.yaml`

Текст для вставки в Claude Code целиком.

## Зачем

`docs/api/openapi.yaml` — производный контракт REST (SSOT — ТЗ). После волны 1 он отстал полностью:
ни одного из добавленных полей в нём нет. Проверено грепом — 0 вхождений `unresolved`,
`match_confidence`, `alternative`, `energy_kj`.

Контракт, который врёт, хуже отсутствующего: по нему пишут фронт и им же объясняют себе поведение
через полгода.

## Контекст

- `docs/04_specs/spec-nutrition-llm-contract.md` §3.1, §6.6, §6.7, §12.5 п.8
- `docs/04_specs/spec-nutrition-retrieval.md` v0.7 §5
- фактический код: `app/contexts/nutrition/api/routes.py`, `resolve/ports.py`

## Что синхронизировать

1. **`unresolved`** — массив в ответе `/analyze` и родственных путей + схема `UnresolvedItem`
   (`name`, `note`, причина). Ответ с пустым `items` и непустым `unresolved` — это **200**, не 502.
2. **`warnings`** на позиции — массив строк-кодов. Перечислить актуальные значения:
   `arith_mismatch`, `kj_suspected`, `kj_kcal_conflict`, `bounds_fail`, `bounds_warn`,
   `portion_warn`, `weight_mismatch`, `barcode_invalid`, `label_disagrees_with_source`,
   `fallback_provider`. Коды брать из кода, а не из этого списка — он может отстать.
3. **`alternative`** — вторая версия чисел при расхождении с источником.
4. **`match_confidence`** — только значение `exact` (вариант D; `confirmed` упразднено).
5. **`energy_kj_100g`** — в схеме извлечённой позиции, nullable.
6. **Кап ввода** — `api_max_images` = 10, превышение даёт **400** с текстом, а не молчаливую обрезку.

## Чего НЕ менять

- `ProvenanceSource` и обязательность КБЖУ в сохраняемой записи. Они не менялись ни разу за волну 1,
  и на это есть тест — не «заодно причесать».
- Пути, методы, коды ответов, кроме перечисленного выше.

## DoD

1. `openapi.yaml` валиден (прогнать любым парсером YAML + структурной проверкой OpenAPI, если есть
   под рукой; отдельную зависимость ради этого не тащить).
2. Тест, фиксирующий, что `ProvenanceSource` и обязательность КБЖУ **не изменились**, остаётся зелёным.
3. Добавить тест соответствия: набор значений `warnings` в `openapi.yaml` совпадает с набором констант
   `FLAG_*` в `resolve/checks.py`. Без него следующий флаг снова разъедется с контрактом — а именно так
   документ и отстал на всю волну.
4. `pytest` целиком зелёный, `lint-imports` 8/8.

Пункт 3 — главный: он превращает разовую синхронизацию в инвариант.
