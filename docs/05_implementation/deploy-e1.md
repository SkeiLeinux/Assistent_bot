## 1. Доставка кода на VPS — выбери путь

Локальная история (git init S0) **не связана** со старым GitHub `SkeiLeinux/lifeManager_bot`.
- **Вариант A (рекомендую):** запушить локальную историю в GitHub — новая ветка `rebuild` (или новый репо) → на VPS `git fetch && git checkout rebuild`. Плюс: дальше деплой = pull, история на месте. Старый default не трогать до стабилизации.
- **Вариант B:** rsync/scp рабочей папки (без `.venv`, `.git`, `*.db`, `.env` — у VPS свой). Быстро, но без истории на сервере.
