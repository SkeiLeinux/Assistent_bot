# Discovery — результаты интервью и фиксация объёма

**Версия:** 1.0
**Статус:** завершено (вход в requirements)
**Ведёт в:** `MVP_Requirements.md`
**Дата:** 2026-06-03
**Что это:** синтез discovery-сессий — провенанс требований. Зафиксированный здесь объём ушёл в requirements.

---

## 1. Метод
Два стейкхолдера проходят один блок вопросов **независимо** (анти-якорение: если один читает ответы другого первым, его картина подстраивается — теряется расхождение). Затем карта расхождений, затем фиксация объёма. Расхождение трактуется как сигнал (скрытые требования, разные ментальные модели), а не шум.

## 2. Стейкхолдеры
- **С.** — системный аналитик/архитектор. Оптика: системы, границы, архитектура.
- **Катя** — бизнес-аналитик, учится на продакта. Оптика: продукт, бизнес-ценность.

## 3. Блок 1 — проблема и видение
Вопросы: (1) чем пользуетесь сейчас и где координация ломается; (2) если бот делает одну вещь идеально — что это; (3) как выглядит «пользуемся постоянно».

**С.:**
- Q1: общий бюджет в Google-таблице (формат устраивает, боль — нет автоматизации); списки/планы/подарки в Telegram-чатах → свалка, нет иерархии и поиска.
- Q2: приоритет — финансовый контроль; идеал — авто-внесение трат с чеков + аналитика + отчёты; сюда же планирование закупок от еды и трат.
- Q3: North Star — полноценный ассистент полного дня (взвешивание, план дня, логирование еды, КБЖУ, витамины, магазин с авто-чеком, отчёт по покупкам, зал, состав тела, план тренировки, активность, отчёт по питанию/тренировкам, ужин из идей, вечерний выбор активности/фильма, сон). MVP (2 мес): списки (идеи/фильмы/покупки) без авто-анализа; загрузка таблицы финансов для анализа; анализ еды (фото+описание, распознавание, КБЖУ, недельная статистика).

**Катя:**
- Q1: Google-таблица для бюджета (удобно, помогает рефлексировать; хочется аналитику и детали); несколько Telegram-чатов по темам (фото, тесты, списки покупок/дел, «что поделать вместе»); хочется всё в одном месте с аналитикой, датами заведения/выполнения, просмотрами фильмов.
- Q2: ежедневно во все чаты не заходит; чаще всего — фото; но без общего хранилища — списки дел/покупок с аналитикой.
- Q3: бот показывает недавние моменты + аналитику по делам/проектам/фильмам; запросила больше вопросов.

## 4. Блок 2 — уточнения
Прицельные вопросы (в основном Кате) по слепым зонам блока 1.

- **Фото (Катя):** сгружает по веткам (едовое/всякое/поездки/тренировки); возвращаются редко (возможны «воспоминания»); ценность — тематическое хранение; Telegram устраивает.
- **Еда/тренировки/здоровье (Катя):** не против в боте (в блоке 1 не назвала из-за рамки «только автоматизация существующего»); чек с разбивкой по продуктам/ценам — нравится (нужна выгрузка + аналитика); тренировки-напоминалки — ок, хочется статистику упражнений/калорий/типов (волейбол/бег/вело), идеал — Huawei Health; добавила медблок (вес/рост/анализы), цикл-аналитику, каталог + расписание витаминов, напоминания о врачах.
- **Аналитика/каденс (Катя):** бюджет — неделя/месяц/квартал/год + ежедневный доступ + произвольный период; разбивку по картам не хочет; недавние моменты по фото — не приоритет; аналитика по каждой сфере.
- **Еда (С.):** модуль уже реализован — 3 режима ввода (текст→ИИ-разбор; фото→распознавание, этикетка точно / блюдо грубо; база→пересчёт по граммам без ИИ), экран подтверждения позиций.

## 5. Карта расхождений
- **Совпадения (твёрдый грунт):** оба — бюджет в Google Sheets устраивает, хотят аналитику поверх (не замену); Telegram-чаты как хранилище = боль, хотят единое структурированное хранилище с метаданными и историей; списки (дела/покупки) — фактический повседневный центр.
- **Расхождения:** драйвер (С. — финансы + здоровье; Катя — списки + фото, финансы как ритуал рефлексии); амбиция финансов (item-level автоматизация vs «больше деталей»); input финансов (Катя изначально хотела ввод в боте → сведено к анализу таблицы в MVP).
- **Слепые зоны и их разрешение:** фото — частая активность Кати, но Telegram устраивает → вне MVP; здоровье/еда — казалось сольной потребностью С., оказалось общим и расширенным (Катя) → общий столп; «тестики» — типизированный список сохранённых ссылок.

## 6. Зафиксированный объём (выход discovery)
- **MVP (заморожено обоими):** списки (типизация, метаданные, поиск, аналитика по типу, приватность подарков); финансы — аналитика по импортируемой таблице (план/факт, иерархия, доходы), каденс D/W/M/Q/Y + произвольный период; питание — существующий дневник + базовые напоминания; сквозная аналитика + ретро-дайджест.
- **North Star (отложено):** автоматизация финансов (ФНС item-level, ввод в боте, сравнение цен, планирование закупок); расширение здоровья (Huawei Health, типы тренировок, медблок, цикл-аналитика, каталог витаминов, врачи, состав тела, сон); фото/«воспоминания»; полный ассистентский день.

**Развилки, снятые в discovery:**
- Способ ввода еды → 3 режима, распознавание уже реализовано.
- Input финансов → MVP: анализ таблицы; автоматизация → North Star.
- Health → MVP: еда + КБЖУ + напоминалки; остальное → North Star.
- Фото → вне MVP.
