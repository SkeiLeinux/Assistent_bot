## P1 (E2) — Чек: от кассы до транзакций

```mermaid
flowchart LR
  subgraph U["Пользователь"]
    u1([Купил, чек на руках]) --> u2{Способ}
    u2 -->|QR| u3["Сканирует QR (showScanQrPopup)"]
    u2 -->|нет QR / не РФ| u4["Фотографирует чек"]
    u2 -->|чека нет| u5["Ручной ввод: сумма+категория"]
    u9["Правит позиции/категории, подтверждает"]
  end
  subgraph B["Backend (finance)"]
    b1["Receipt ACL: канал A/B (qrraw) либо D (vision)"]
    b2{"Канал ответил?"}
    b3["Сырьё сохранено (Receipt.raw_ref), статус «к разбору»"]
    b4["ParsedReceipt → черновик позиций"]
    b5["Категоризация (ADR-0011): правила + LLM-подсказка"]
    b6[("Receipt + ReceiptItems + Transactions")]
    b7["Аналитика E1 видит факт сразу (агрегат от Transaction)"]
  end
  EXT["proverkacheka / API ФНС / Groq vision"]

  u3 --> b1
  u4 --> b1
  b1 <--> EXT
  b1 --> b2
  b2 -->|нет| b3
  b2 -->|да| b4 --> b5 --> u9 --> b6 --> b7
  u5 --> b6
  b3 -.->|"повторный разбор позже"| b4
```

Свойства: ничего не пишется без подтверждения (analyze→confirm→save); фейл канала не теряет чек (сырьё сохраняется); ручной ввод — равноправный вход, не исключение.

## P2 (E2) — Переход SSOT: таблица → транзакции (ADR-0007)

```mermaid
flowchart LR
  s1([Старт E2]) --> s2["Параллельный период: транзакции в боте + таблица как раньше"]
  s2 --> s3{"Сверка месяца:\nΣ транзакций ≈ таблица?"}
  s3 -->|расхождения| s4["Разбор причин (забытые траты? канал?) → правки привычек/категорий"] --> s2
  s3 -->|сходится N месяцев подряд| s5["Таблица → архив; Import ACL → консервация (код остаётся, не зовётся)"]
  s5 --> s6["Катин ритуал: экспорт периода (xlsx) из бота (F2.6)"]
  s6 --> s7([Выход-гейт E2])
```

Длительность параллельного периода и критерий «сходится» — параметры ADR-0007 (страховка от потери доверия к данным).

## P3 (E3) — Huawei-импорт здоровья

```mermaid
flowchart LR
  subgraph U["Пользователь"]
    h1(["Напоминание-пресет: «запроси экспорт» (раз в 1–2 нед)"])
    h2["Huawei Health: Privacy center → Request your data → Health"]
    h3["Получает zip на почту (минуты), скачивает"]
    h4["Грузит zip в Mini App (+ пароль архива)"]
    h7["Смотрит отчёт импорта: новые периоды, конфликты"]
  end
  subgraph B["Backend (health/importing ACL)"]
    b1["Распаковка → парс JSON-папок (Health detail / Sport / Sleep …)"]
    b2["Нормализация → Measurement/Workout"]
    b3{"Пересечение с ручными записями?"}
    b4["Дедупликация по правилу ADR-0008 (источник-приоритет)"]
    b5[("Идемпотентный upsert по периодам")]
    b6["Zip уничтожается после разбора (медданные не храним сырьём)"]
  end
  h1 --> h2 --> h3 --> h4 --> b1 --> b2 --> b3
  b3 -->|да| b4 --> b5
  b3 -->|нет| b5
  b5 --> b6 --> h7
```

Паттерн идентичен импорту бюджета (E1): ручная выгрузка → ACL → идемпотентный upsert → отчёт. Отличие — уничтожение сырья (приватность).

## P4 (E4) — Утренний план дня

```mermaid
flowchart LR
  subgraph S["scheduler"]
    s1(["job: morning_plan (per-user время, таймзона kernel)"])
  end
  subgraph A["assistant (read-only)"]
    a1["Сбор: reminders сегодня · TASK-OPEN с близкими датами · тренировка (E3, если расшарена) · идея ужина (Nutrition/Lists)"]
    a2["LLM-композиция в человеческий текст (границы — ADR-0012)"]
    a3{"План пуст?"}
  end
  subgraph N["notifications"]
    n1["deliver(user, план, kind=morning_plan)"]
  end
  s1 --> a1 --> a2 --> a3
  a3 -->|да| skip([Не шлём])
  a3 -->|нет| n1 --> u(["Пользователь читает план, тапает в Mini App"])
```

Per-user (не per-family): план личный, состав фильтрован видимостью (цикл-фаза Кати не попадает к С. без явного шаринга).
