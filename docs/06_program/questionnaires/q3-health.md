### В4. [Катя] Витамины. Опиши, как должен выглядеть каталог «что у нас есть» (поля: название/производитель/состав/чьё/сколько осталось?) и расписание (время приёма, курсами с датами начала-конца?). Кто его ведёт?
**Ответ Кати (2026-06-25):** ✅ Каталог: название / производитель / состав / сколько осталось / кол-во в банке + **ссылка где заказывала** + **с чем можно совмещать** (из имеющихся витаминов). Расписание: время приёма / приняла-сегодня-или-нет / напоминание под её ритм и примерно заданное ею / даты начала-окончания курса + отмена всех напоминаний / **возобновление курса**. Ведёт сама («свои витамины могу и я вести»). NEW vs текущих reminders: ссылка-заказ, матрица совместимости, пауза/возобновление, персональное владение.
