# Артефакты смоука выкатки

Сюда пишет `scripts/smoke.py` — по одному JSON на прогон
(`<дата>_smoke.json`): база, ожидаемый коммит/модель, коридор и результат
каждого кейса с телом ответа.

**Каталог свой, и это не мелочь.** Артефакты замеров источника уже дважды
роняли сводку раннера, потому что лежали в `tests/eval/runs/` — каталоге
инструмента с другим контрактом (хвост №4 блока 11). Ни `runs/`, ни `probes/`
раннера сюда не годятся и наоборот; на это есть тест
(`tests/test_smoke_cases.py::test_smoke_artifacts_stay_out_of_the_runner_dirs`).

Прогоны мутантов (мёртвый порт, подставной эталон) — мусор, а не запись:
их артефакты удаляй. Запись имеет смысл только для прогона против реального
прода после выкатки.
